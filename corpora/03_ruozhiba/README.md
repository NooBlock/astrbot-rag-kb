# 03_ruozhiba — 弱智吧语料库 🧠

百度贴吧「弱智吧」社区风格语料，供给 AstrBot 知识库「弱智吧语料库」（kb_name=`弱智吧语料库`）。
目标是让检索到的片段带上弱智吧的「无厘头神提问 / 一本正经地歪解」气质，而不是科普事实。

## 构建方法

### A. 标题组（962 条 chunk）

1. 从 `wisdomBar_raw.csv` 取 92509 条原帖标题，清洗后可用 **85354** 条：
   - 去 HTML 标签与实体、控制字符、多余空白、首尾标点；去掉贴吧「rt/如题」后缀；
   - 去 URL、联系方式、广告（加微/代购/刷单/优惠券/公众号等）；
   - 去吧务/签到/水贴/申精/封禁等元帖；
   - 长度限制 8–60 字（过短无信息量、过长非标题体），非中文字符占比 >50% 的火星文/乱码丢弃；
   - 完全重复标题去重。
2. **抽样**：固定种子 `random.Random(20261026).sample`，从 85354 条中等概率抽 **4800 条**（约 5.6%）。
   不按回复数/热度筛选，避免只留「爆款」而丢掉长尾梗。
3. **分桶**：按关键词命中数归入 12 个主题（科学物理、生物医学、数学逻辑、历史社会、动物植物、日常起居、情感家庭、语言文字、宗教哲学、工作职场、网络科技、经济消费），命中不到则进「杂谈」；
   「杂谈」桶再按弱智吧反复出现的固定角色（王老汉、小明、王警官、食人族、小红、老王、院长等 ≥5 条的系列）与社会新闻体（男子/女子/记者/据报道）细分。
4. 每个桶按 4–6 条（目标 5 条）均衡合并为 1 条 chunk，使同一 chunk 内是同主题/同角色的段子，避免语义稀释。
5. 格式：

   ```
   弱智吧神提问（生物医学）：
   1. 病人死亡十分钟后医生终于遗憾的拔掉空气加湿器插回呼吸机插头
   2. ……
   ```

### B. 问答组（358 条 chunk）

1. 从 `ruozhiba_qa.json` 读取 1496 组 QA，清洗后可用 **1434** 组：
   - 答案长度上限 180 字（更长的多为长篇说教，梗味被稀释）；
   - 去 URL/联系方式/空串/重复对；HTML 实体与多余空白同上去除。
2. 按相同 12 主题分桶，每个桶 3–6 组（目标 4 组）合并为 1 条 chunk，单块控制在 1150 字符内；格式：

   ```
   弱智吧问答（一本正经地解释无厘头提问）：
   问：人在喝西北风时，雾霾算是添加剂吗？
   答：……

   问：……
   答：……
   ```

## 抽样策略

- 标题：85,354 条可用标题中固定种子等概率抽 4,800 条（seed=20261026，可复现），覆盖各主题约 5–6%。
- 问答：清洗后 1,434 组**全量使用**，不做抽样。
- 合计 **1,320 条 chunk**（962 标题组 + 358 问答组），长度 83–771 字符，平均 229。

## 注意事项 / 已知局限

- `kirp/ruozhiba-raw` 只有帖子标题/正文，**没有回复**，所以标题组 chunk 只呈现「神提问」风格；真正带「答」的 chunk 来自 `LooksJuicy/ruozhiba`，答案是「认真解释无厘头问题」的冷面幽默（另一种弱智吧风味），两组语气有差异，manifest/README 已注明。
- 标题来自贴吧抓取，部分标题被贴吧 60 字上限截断（如「……结果里边啥也没有」），未做补全，保留原状。
- 弱智吧内容包含大量荒诞、黑色、冒犯性玩笑（涉及死亡、疾病、婚恋、暴力等），仅作风格语料；实际对话使用时应避免照搬攻击性内容。
- 标题组 chunk 的语义由主题/角色标签托底；「杂谈」桶中少量 chunk 仍是不同段子并列，主题一致性弱于其他桶。
- 两个来源的原始文件均保留在 `raw/`；如仓库体积敏感，可只保留 URL 并删除 14 MB 的 CSV。

