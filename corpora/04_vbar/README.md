# V吧黑话库（04_vbar）

V 圈 / V 吧黑话与圈层用语精标库。每条 1 个词条，自包含、可单独检索。

## 文件

- `chunks.jsonl`：每行 `{"id": int, "text": str}`，共 120 条。
- `manifest.json`：AstrBot 知识库元信息。
- `raw/`：构建期抓取的原始页面（知乎回答、萌娘百科用语表等）与抽取脚本，供追溯。

## 来源（全部可公开访问）

1. **知乎《v吧常见黑话大全》（节选）**，作者 XMMATRIX
   <https://www.zhihu.com/question/434737537/answer/1641781496>
   提供 v 篇（具体虚拟主播黑称）、组织篇、群体篇、其他（独轮车/SC/同接/塔照/开盒 等）约 60 条。
2. **萌娘百科《虚拟UP主用语与梗》**
   <https://zh.moegirl.org.cn/虚拟UP主用语与梗>
   提供约 60 条通用 V 圈用语（DD、单推、毕业、出道、冲塔、棉花糖、切片、转播man、中之人、皮套、SC、同接数 等）。

只收录上述两处来源能逐条对应的词条；无法核实出处的称谓语未入库（见下“已知局限”）。

## chunk 格式

```
【词条】<词条名，含常见别名>
【释义】<来源释义，清理 markdown 后的纯文本>
【出处/语境】<来源页面 + 条目名>
【用法示例】<仅部分常见词条提供；示例句由构建者按圈内语境撰写，非原文引用>
```

## 构建方法

1. 通过 r.jina.ai 文本化代理抓取知乎回答页与萌娘百科页面（知乎直连 403、萌百有 Cloudflare 挑战）。
2. 从萌百页面按 `### 词条` 分节抽取释义，清理链接/图片/脚注标记；从知乎回答按“v篇/组织篇/群体篇/其他”分节解析“别名：所指”结构。
3. 黑称类词条统一附加使用提醒；剔除无法自包含的条目（如只有一个反斜杠的条目）与低信息词条。
4. 写 `chunks.jsonl` 后用 `tools/validate_corpus.py` 校验（JSON 合法、无空串、无重复、长度区间、manifest 条数一致）。

## 已知局限 / 存疑

- **未收录**任务示例中的「舰长 / 提督」：这两个是 B 站直播“大航海”付费等级词，属于平台机制而非 V 吧黑话；本次未找到可引用的公开释义页（萌娘百科无对应条目），按“可追溯优先”原则暂缺，未编造出处。
- 知乎原回答本身标注为“节选”，别名与所指关系来自该回答；个别黑称存在争议（原答案已注明“有争议”），本库照录并保留括号说明。
- 萌百释义保留原站措辞，个别条目年代较早，可能已与当下用法有差异。
- 【用法示例】为构建者按语境撰写，仅作使用示范，不是原出处的引用。

## 许可与使用

知乎回答、萌娘百科内容版权归原作者与站点所有（萌百内容不可商用）。本库为个人自用学习/语料实验用途，请勿商用或再分发原文。黑称类词条带有阵营与贬义色彩，仅用于理解语料，不建议在粉丝向场合使用。

## 复现（可选）

> `chunks.jsonl` / `manifest.json` 已是最终产物，可直接导入，**普通使用者无需重新构建**。
> 原始抓取数据（`raw/`）因体积与第三方版权原因不随本仓库发布。
> 原始页面为人工检索抓取（知乎 / 萌娘百科 / B 站），没有完整下载脚本；`build_vbar.py` 读取 `raw/` 中的文本，仅作构建期参考。
