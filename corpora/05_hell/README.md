# 地狱笑话库（05_hell）

中文「地狱笑话 / 黑色幽默」精标语料，每条附【类型】与安全使用提示。

## 文件

- `chunks.jsonl`：每行 `{"id": int, "text": str}`，共 81 条。
- `manifest.json`：AstrBot 知识库元信息。
- `raw/`：构建期抓取的原始页面、公开数据集样本与抽取脚本，供追溯。

## chunk 格式

```
【地狱笑话】<笑话原文>
【类型】<地域/职业/病症/灾难/历史/其他>
【使用提示】仅在对方主动玩梗且关系足够熟时使用；涉及真实受害者、具体地域/民族/性别/疾病/灾难时默认不使用或改写。<按类型的额外提示>
```

## 筛选与安全边界（重要）

**不收录**：
- 指向真实悲剧/事件的内容（如 911、泰坦尼克、新冠疫情、伊拉克战争、广岛长崎原子弹等）；
- 指向未成年人、孤儿、儿童受害场景的内容；
- 指向现实中可识别个人（真实名人死亡、现实政治人物、具体案件当事人）的内容；
- 种族/民族歧视、性别攻击、性暗示为主的条目。

**保留但加严提示**：病症、灾难、地域、历史、职业类条目均在使用提示中追加了“默认不使用/仅熟人/禁止对当事人使用”等限制。筛选后每条均保留原始措辞，仅做空白归一与英文残留清理，不改写笑点。

## 构建方法与局限

1. 网络检索可用的中文「地狱笑话」合集大量以图片（梗图）形式传播（知乎专栏、B 站专栏/动态、贴吧合集均如此），纯文本可解析来源有限；本库因此以煎蛋译文系列 + 搜狐谐音梗文章 + 公开段子数据集三路拼成，宁可少收，未编造出处。
2. 因此部分条目的“地狱浓度”一般（偏普通黑色幽默），已在 manifest 中如实说明；若后续拿到可解析的纯文本中文地狱笑话源，可按同格式扩充。
3. 煎蛋、搜狐、知乎内容版权归原作者/站点所有；duanzi.json 为公开 GitHub 数据集。本库仅供个人自用学习/语料实验，请勿商用或再分发原文。

## 使用建议

本库是**风格与噪声语料**，不是聊天素材库：默认不主动对任何人使用；仅在对方先玩梗、关系足够熟、且不涉及在场者身份（地域/职业/疾病等）时，才可考虑借梗。对外发布内容建议整体不用。

## 复现（可选）

> `chunks.jsonl` / `manifest.json` 已是最终产物，可直接导入，**普通使用者无需重新构建**。
> 原始抓取数据（`raw/`）因体积与第三方版权原因不随本仓库发布。
> 原始页面与段子为人工检索筛选；`fetch_jandan*.py` 可抓取煎蛋两个系列，`build_hell.py` 读取 `raw/` 中的 JSON 生成产物。

```powershell
# 在仓库根目录执行；脚本需要 requests / beautifulsoup4 / lxml
# 可选：抓取煎蛋两个系列到 corpora/05_hell/raw/
python scripts\build\05_hell\fetch_jandan.py
python scripts\build\05_hell\fetch_jandan_meipin.py
# 需要 raw/ 里已有抓取/整理好的 JSON，再生成产物
python scripts\build\05_hell\build_hell.py
python tools\validate_corpus.py corpora\05_hell
```
