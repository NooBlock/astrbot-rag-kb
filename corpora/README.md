# corpora/

5 个 RAG 语料库的最终产物。每个目录包含：

| 文件 | 说明 |
| --- | --- |
| `chunks.jsonl` | 每行一个 `{"id": int, "text": str}`，直接可嵌入的完整片段 |
| `manifest.json` | 知识库元信息（名称、emoji、来源、许可、条数、构建时间） |
| `README.md` | 该库的来源、清洗规则、统计、已知局限 |

| 目录 | 知识库名 | emoji | 条数 | 层 |
| --- | --- | --- | --- | --- |
| `01_cheer_terms/` | 网络流行语释义库 | 🗣️ | 1219 | 核心释义层 |
| `02_meme_style/` | 网梗对话风格库 | 💬 | 1804 | 风格语料层 |
| `03_ruozhiba/` | 弱智吧语料库 | 🧠 | 1320 | 社区风格层 |
| `04_vbar/` | V吧黑话库 | 🎭 | 120 | 社区风格层 |
| `05_hell/` | 地狱笑话库 | 💀 | 81 | 社区风格层 |
| **合计** | | | **4544** | |

`_state/imported.json` 是导入时的状态记录（kb_id、条数、sha256、耗时），仅作参考，
在新机器上导入后会重新生成。

> 语料为公开数据/公开资料的二次整理，**多数上游未声明开放许可**，仅供学习与自用。
