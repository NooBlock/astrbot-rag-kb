# wiki 导航

这里是 **astrbot-rag-kb** 的使用文档。项目本身是一组整理好的中文互联网梗 RAG 语料（5 个 AstrBot 知识库，合计 4544 个 chunk），加上导入工具和这些说明。

> 只想先跑起来？直接看[快速开始](快速开始.md)。语料能不能商用？先看[许可与合规](许可与合规.md)。

## 三条推荐阅读路径

**① 使用者（只想让机器人变懂梗）**

1. [快速开始](快速开始.md) —— 跑通;
2. [导入到 AstrBot](导入到%20AstrBot.md) 的「如何让知识库真正参与对话」—— 把 `kb_names` 和 `kb_agentic_mode` 配对设好;
3. [FAQ](FAQ.md) —— 遇到问题再查。

**② 评估者（决定要不要用/要不要发布）**

1. [语料说明](语料说明.md) —— 看清每个库的内容与质量;
2. [许可与合规](许可与合规.md) —— 看清上游许可与再分发风险;
3. [数据字典](../docs/数据字典.md) —— 确认格式与可移植性。

**③ 维护者（长期运营、自己扩充）**

1. [数据字典](../docs/数据字典.md) —— 先定格式;
2. [维护与更新](维护与更新.md) —— 重建、换模型、备份、定时更新;
3. [语料说明](语料说明.md) 的「已知局限」—— 知道哪些地方容易出问题。

## 关于本目录

- 本 wiki 以 Markdown 存在仓库 `wiki/` 目录，可直接在 GitHub 仓库中浏览；如果迁移到 GitHub Wiki，页面路径以平台生成的链接为准。
- 文中命令默认在仓库根目录执行。`python` 指 AstrBot 所在环境的 Python 3.12（Windows：`astrbot\.venv\Scripts\python.exe`；Linux：`astrbot/.venv/bin/python`）。
- 所有示例统一使用占位地址 `http://127.0.0.1:6185` 与 `<YOUR_TOKEN>`，不含任何真实凭据。

## 一句话免责声明

语料来自公开数据集的二次整理，许可多为「未声明 / 仅限自用」；本项目不主张对第三方语料的权利，**仅供学习与个人自用，商用与再分发前请自行核对上游许可**。娱乐用途之外，请自行确保符合所在平台与地区的法律法规。
